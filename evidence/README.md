# Evidence folders

Directories are intentionally empty placeholders. Add genuine evidence after running the tests.

Suggested structure:
- `screenshots/chrome-desktop/`
- `screenshots/android/`
- `screenshots/tablet/`
- `recordings/chrome-desktop/`
- `recordings/android/`
- `recordings/tablet/`

Name evidence using its test/bug ID, e.g. `TC-ONB-003-back-navigation.mp4`. Before committing, remove passwords, tokens, email inbox details, student/guardian identifiers, and unrelated private information. Never create fake evidence.
