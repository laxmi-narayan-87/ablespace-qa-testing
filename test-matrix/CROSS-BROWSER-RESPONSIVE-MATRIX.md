## Responsive checklist
- All primary controls visible or reachable.
- Long lists scroll or paginate.
- Keyboard does not obscure the only path forward or save action.
- No clipped labels, validation messages, modal buttons, or reports.
- Touch targets are usable.
- Changes persist after save and revisit.
