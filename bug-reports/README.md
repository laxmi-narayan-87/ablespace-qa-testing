# Bug Reports

Create one file per bug after reproduction, e.g. `BUG-ONB-001-missing-forward-navigation.md`.

Record environment, prerequisites, exact steps, expected/actual results, frequency, severity/priority, impact, and evidence links. Keep candidate defects separate from product-rule questions or usability suggestions. Do not treat a typing-only observation as a confirmed validation bug without checking submission/save behavior. Do not create empty speculative reports.
